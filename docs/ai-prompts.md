# AI Prompts

AI assistance was used during development as a development aid for implementation, debugging, architecture discussions and documentation.

The application code was reviewed, tested and integrated manually during development.

## Main Areas Where AI Assistance Was Used

### Project Setup and Architecture

AI was used to discuss the project structure, Next.js App Router organization, authentication flow and separation between Staff and Instructor workflows.

### Database and Prisma

AI assistance was used while working with Prisma and the PostgreSQL database, including:

- Prisma 8 configuration
- Database schema design
- Prisma query syntax
- Debugging database queries
- Relationships and constraints

### Authentication and Authorization

AI was used to help implement and debug:

- Clerk authentication
- Application user creation
- Staff and Instructor roles
- Server-side authorization
- Instructor-specific access checks

### API Development

AI assistance was used while implementing and debugging API routes for:

- Classes
- Sessions
- Rooms
- Members
- Users
- Instructors
- Bookings
- Attendance
- Membership alerts
- Booking history
- CSV export

### UI Development

AI was used to help build and debug React/Next.js interfaces using Tailwind CSS and shadcn/ui.

This included forms, dialogs, tables, filters, navigation and role-specific screens.

### Debugging and Testing

AI assistance was used to investigate runtime errors, API errors, Prisma issues, authentication problems and UI warnings.

The implemented workflows were manually tested during development.

### Documentation

AI was also used to help structure and draft project documentation, including the architecture, schema, implementation plan and technical decisions.

## Example Prompt Categories

Examples of the types of prompts used during development included:

- Help configure Prisma with the current Prisma 8 workflow.
- Help design the relational database schema for the booking system.
- Help implement Staff and Instructor authorization.
- Help debug Prisma query and runtime errors.
- Help implement booking capacity and waitlist promotion.
- Help implement recurring sessions and instructor/room conflict checks.
- Help implement attendance restrictions for assigned instructors.
- Help debug Next.js and shadcn/ui issues.
- Help review the project before final deployment and submission.

AI-generated suggestions were treated as development assistance rather than as a substitute for testing or technical decisions. Final implementation choices were made based on the requirements of the assignment and the behavior of the application.
